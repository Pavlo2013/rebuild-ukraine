# Rebuild Ukraine

Interactive React + Three.js simulation for rebuilding Ukraine.

## Included source assets

- `assets.py`, `download-assets.py`, `download.py`, and `finish.py` — Wikimedia Commons asset discovery/download scripts.
- `app-2.js` through `app-7.js` — application variants supplied in the project source.

The application expects the project's supporting ES modules (`regions.js`, `economy.js`, `city.js`, UI components, data modules, and vendor dependencies) plus the generated `assets/` directory.
